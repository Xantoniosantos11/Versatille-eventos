# Versatille Eventos

Primeira versão do aplicativo web/PWA.

## 1. Configurar o Supabase
Abra `config.js` e substitua:
- `COLE_AQUI_A_URL_DO_SEU_PROJETO`
- `COLE_AQUI_A_CHAVE_ANON_OU_PUBLISHABLE`

Use somente a chave pública/anon (ou publishable). NUNCA use `service_role`/secret.

## 2. Testar
Hospede os arquivos em um serviço de hospedagem estática ou rode com um servidor local.

## 3. Próximas etapas
- Cadastro de eventos
- Cadastro de produtos
- Entrada e ajuste de estoque
- Tela de venda
- Pagamentos
- Relatórios
- Realtime entre celulares
- PWA/offline com fila de sincronização
